Generated by `make ingest SOURCE=factored`. Aggregates only: no rows, identifiers or PII.

## Run

| Parameter | Value |
|---|---|
| Mapping | `banking_core/seed/ingest/sources/factored.json` |
| Dataset cutoff | 2026-06-18 |
| Anchor date (`INGEST_ANCHOR_DATE`) | 2026-09-27 |
| Date shift (anchor − cutoff) | 101 days |
| History window | last 90 days before the cutoff |
| Customer cap (`INGEST_MAX_CUSTOMERS`) | 5000 |

Timestamps after the cutoff are clamped to just before it, then every event timestamp is shifted by the same number of days so the history ends at the anchor. Birth dates are not shifted; card expiry is shifted but not clamped.
